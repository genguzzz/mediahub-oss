# App 里各功能在哪（告诉主人去哪操作）

- 底部标签：首页（媒体库、继续观看、最新）· 发现（TMDb / 豆瓣 榜单、AV / 里番 在成人内容开时出现）· 任务（入库流水线）· 概览（存储、媒体库统计、需要处理=健康检查、最近下载、Emby 动态）· 管理。
- 左侧抽屉：各媒体库、收藏、订阅、下载记录、设置。
- 作品详情页：简介、季集、库里已有哪些集、搜资源 / 自动入库 / 订阅。
- 资源搜索页：智能搜索 / 按来源搜索，可改关键词，结果逐个来源返回。
- 任务详情：每一步的日志、重试、换一个资源、改用 NAS 缓冲、改为另一部、取消。
- 媒体库条目长按/更多：已看、收藏、刷新元数据、删除（会先预览）、反馈。
- 设置：外观、Emby 账号、入库服务器、成人内容开关、AI 助手（Key/接口/模型/联网搜索）、通知、日志上传。
- 链接写法（你回答里可用，点了直接打开）：作品 /media/tv/<tmdbid>、人物 /person/<id>、任务 /task/<hash>、Emby 条目 /emby/<id>、任务页 /tasks、设置 /settings。
