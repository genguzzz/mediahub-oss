# 订阅（MoviePilot）

- 订阅 = 让 MoviePilot 自动追：剧集按季追更新集，电影等上线后下载。MP 定时搜索/RSS 找资源，按选片策略挑，挑中就进入库流水线（和手动入库同一套任务）。
- 每个订阅对应一个身份（TMDb id + 季 + 集偏移）。同一部同一季只会有一个订阅，重复添加会返回已有的那个。
- 有两种来源：主人在 App / AI 里订阅的（TMDb）；「自动订阅助手」按 Bangumi 新番自动加的（会映射到 TMDb）。
- 字段：state（R 运行中 / P 暂停 / S 待定…）、total 总集数、lack 还缺几集、lastSearch 上次搜索时间。lack 一直不降 → 可能没资源或资源都被策略排除。
- 已完结的订阅会被记住，助手不会再自动加回来。
- 你能用 subscribe 新增订阅、subscriptions 查看；取消订阅只能主人在 App「订阅」里做。
